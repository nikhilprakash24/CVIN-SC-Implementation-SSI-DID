IEEE 1609.2 — V2X Security Services

IEEE 1609.2 · WAVE security · X.509 / ECDSA P-256 · pseudonym certificates

The PKI baseline: certificate-based (X.509 / ECDSA) authentication of V2X messages, with enrollment and short-lived pseudonym certificates. It is the traditional-identity counterpart against which SSI credential verification is compared in the V2V latency study.

What it is
The IEEE standard for security services in Wireless Access in Vehicular Environments (WAVE): a public-key infrastructure that authenticates V2X messages with ECDSA signatures and X.509-style certificates, using enrollment certificates plus rotating pseudonym certificates for driver privacy.
Reference
standards.ieee.org/ieee/1609.2
Role in thesis
The PKI baseline for the V2V latency comparison — the incumbent against which the SSI (DID / VC) credential-verification path is measured. It represents the centralized-trust alternative to the blockchain-identity substrates.
Where used
cv2x-testbed/identity/ (PKI provider — cv2x-testbed/identity/standard/pki_identity.py)
Provenance
The PKI identity provider was implemented by the researcher per IEEE 1609.2 (with ETSI TS 102 940/941 for the enrollment/pseudonym flow): ECDSA P-256 keypairs, an enrollment certificate, and pseudonym certificates. See PROVENANCE.md.
Note · §4.4

PKI warm-verify 0.102 ms vs SSI 0.165 ms — both far under the ~100 ms V2V budget. Scope caveat (RESEARCH_AUDIT §4.4): these are cryptographic verification only. The radio access / MAC contention, propagation, queuing, and application-processing terms of the end-to-end budget are excluded (no network stack; mock mobility; single host). The defensible claim is narrow: credential verification is not the V2V bottleneck.
