Gas Benchmark — 9-Standard Cost Register

gas_benchmark.json · solc 0.8.24 (viaIR, opt 200) · OZ 5.0.2 · Hardhat-local (chainId 31337) · N=30

The per-operation gas cost of every identity standard, measured as the exact receipt.gasUsed of one representative transaction per (standard, operation) on a fresh in-process Hardhat network. This is the primary evidence for H1 (minimal standards are ≥10× cheaper) and feeds the H5 security/performance frontier.

What it measures
Deploy + five lifecycle operations (createIdentity, updateAttribute, addDelegateOrClaim, revoke, transferOwnership) across nine identity standards plus the MOBI-VID-V2 application profile; null where a standard has no analogue for an operation.
Method
Full benchmark re-run 30 times on a fresh Hardhat network each time; gasUsed aggregated per cell. EVM gas is deterministic for fixed calldata + pre-state, so identical values across runs (stdev 0, CI width 0) is the expected reproducibility result. Setup txs (role grants, issuer auth) are excluded from operation gas.
Key numbers
createIdentity ranges 52,178 (CVIN-Combined) and 52,612 (ERC-1056) at the low end to 1,704,992 (ERC-725xy) at the high — a ~33× spread; ERC-1056 is roughly 10× under ERC-721 (542,429) and ERC-725 (528,647). The ERC-4337 EntryPoint indirection adds +46,862 gas/op (96,228 vs 49,366).
Source file
4_comparison-framework/results/gas_benchmark.json (+ gas_benchmark_stats.json for the N=30 determinism proof)
Provenance / caveat
Produced by the researcher's Hardhat harness (1_blockchain-identity/scripts/benchmark_gas.js). Caveat: gas is measured on Hardhat-local — deterministic, so the relative comparison holds, but absolute fiat cost is gas-price dependent and no public-testnet (Sepolia) witness exists yet. See PROVENANCE.md.
Confirms H1

createIdentity spans 52,178 to 1,704,992 gas — a ~33× spread that puts the minimal event-log substrates an order of magnitude below the rich-state standards. Every one of the 30 runs returned byte-identical values (stdev 0), so the point estimates are exact, not single-sample flukes. (Results §5.2.)
