LSP8 — Identifiable Digital Asset

LUKSO LSP8 · bytes32 tokenId · per-token ERC-725Y data

The LUKSO take on a unique-asset identity: each vehicle is a bytes32 token whose id is keccak256(VIN) and whose attributes live in a per-token ERC-725Y-style data store. A middle-weight token substrate, measured with a minimal representative implementation.

What it is
LSP8 Identifiable Digital Asset represents each vehicle as a unique bytes32 token id (here keccak256(VIN)), with attributes written into a per-token LSP2/ERC-725Y-style key/value data store. Transfers use the LSP8 5-argument transfer; burning the token revokes the identity.

Minimal repr.

Creating an identity costs 149,352 gas — a middle-weight token substrate, roughly 3× the ERC-1056 baseline. Because operator hooks and universal-receiver probing are omitted, this is a lower bound for a fuller LSP8 deployment. (Results §5.2.)
