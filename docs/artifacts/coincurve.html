coincurve — Native secp256k1

coincurve (optional; native libsecp256k1, ~40× faster)

The native libsecp256k1 binding used for fast secp256k1 sign/recover in the V2V latency measurement; when absent, an eth-keys pure-Python fallback is used instead.

What it is
A Python wrapper around Bitcoin Core's libsecp256k1, giving C-speed ECDSA sign/recover on the secp256k1 curve.
Version
Unpinned / optional (SOURCES.md §4); auto-detected at runtime, with a pure-Python fallback when not installed.
Role in thesis
Backs the SSI signing/verification path in the V2V latency benchmark; the reported ~40× speed-up over the pure-Python fallback is why the SSI warm figure sits in the sub-millisecond range.
Where used
cv2x-testbed/sumo/sumo_identity_integration.py, cv2x-testbed/sumo/run_v2v_stats.py (auto-detected; see cv2x-testbed/sumo/README.md)
Provenance
Optional native backend, used by the researcher for the V2V perf path. See PROVENANCE.md.
Caveat

The SSI warm-verify figure (0.165 ms) is coincurve-backed and hardware-dependent; absolute latencies reflect this host's warm, uncontended core (RESEARCH_AUDIT §4.4/§4.5).
