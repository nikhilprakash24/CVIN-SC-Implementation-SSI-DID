## 2. Conventions every work package follows

- **Sources.** Specs and papers are read at source. An entry not yet read stays marked **"recalled"** and cannot
  support a claim.
- **Numbers.** Only register rows (`docs/MEASUREMENT_CONDITIONS.md`), cited by row number with their caveats. No new
  number is made without a pre-registered run.
- **Definitions.** The IDTx definition is quoted verbatim from `ANALYSIS.md` §4.1 and never reworded (AR-2).
- **Figures.** Every figure is generated by a script, ships with a data table in a `FIGURES.md`, is legible in light
  and dark, and follows the style of `docs/phase2/focus/make_focus_figures.py`. No hand-drawn figure is committed.
- **Pseudocode.** Each listing cites the `file:line` it abstracts. A listing with no code behind it is labelled
  *specification only*.
- **Placement.** Each output file declares its home from §1 in its header.
