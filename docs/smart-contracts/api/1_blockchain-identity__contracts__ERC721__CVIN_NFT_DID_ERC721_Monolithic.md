## contract `CVIN_NFT_DID_ERC721_Monolithic` is `IERC165`, `IERC2981`, `Ownable`

**CVIN_NFT_DID_ERC721_Monolithic** · CVIN research project

Hand-written ERC-721 (core + Metadata) with ERC-2981 royalties in a single file, the same surface as CVIN_NFT_DID_ERC721 without the toll functions.

*Dev:* Exists to compare the gas cost of OpenZeppelin inheritance with a monolithic file. Uses OpenZeppelin Contracts 5.0.2 only for Ownable, Strings and the interface types (IERC165, IERC2981, IERC721, IERC721Metadata, IERC721Receiver). Deviations from ERC-721 / OZ v5: does not inherit IERC721 in Solidity (`is IERC165, IERC2981, Ownable`) but still reports IERC721 in supportsInterface; no Enumerable extension; setApprovalForAll rejects `operator == msg.sender`; `_transfer` emits an Approval event while clearing approvals; `mint` uses `_mint`, not a safe mint. The D-series balance fix (`+= 1` instead of `+= tokenId`) is covered by balanceCountsTokens.regression.test.js.

- **standard:** ERC-721 Non-Fungible Token (core + Metadata) https://eips.ethereum.org/EIPS/eip-721
- **standard:** ERC-2981 NFT Royalty Standard https://eips.ethereum.org/EIPS/eip-2981
- **standard:** ERC-165 Standard Interface Detection https://eips.ethereum.org/EIPS/eip-165
- **security:** _burn, _setTokenRoyalty and _resetTokenRoyalty are internal and never called: no burn, and per-token royalties are unreachable.
- **security:** The stored URI is prefixed by the placeholder base URI. No VIN binding.
- **see:** docs/smart-contracts/03-token-standards-erc721-erc1155-lsp8.md
