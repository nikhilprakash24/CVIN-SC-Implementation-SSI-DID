## contract `SchnorrEcrecoverVerifier`

**SchnorrEcrecoverVerifier** · CVIN research project

Verifies a Schnorr proof of knowledge of a secp256k1 private key, using the ecrecover precompile.

*Dev:* Gas baseline for Plan 1 to-do 1 (sigma protocol vs Groth16). ecrecover is used to compute address(s*G - e*P) and the Fiat-Shamir challenge e = keccak256(addr(R) || parity || px || message) is recomputed and compared. The proof is not tied to any ERC-1056 identity. Python prover: 5_zkp-agent-identity/zkid/schnorr_evm.py; gas is recorded by scripts/measure_gas.js.

- **standard:** Schnorr identification / Fiat-Shamir (non-interactive PoK of a discrete log), secp256k1 (https://www.secg.org/sec2-v2.pdf)
- **standard:** ecrecover precompile 0x01 (Ethereum Yellow Paper, Appendix E: https://ethereum.github.io/yellowpaper/paper.pdf)
- **security:** No replay protection: the same (px, message, e, s) can be resubmitted to `prove`; `message` must carry any nonce or context.
- **security:** Research gas baseline only; it proves key knowledge, not control of any on-chain identity.
- **see:** docs/smart-contracts/05-zkp-and-idtx.md (section 3.2)
- **see:** 5_zkp-agent-identity/test-contracts/zkvin_gate.test.js (Schnorr verifier test)

### Functions

#### `verify`

```solidity
function verify(uint8 parity, bytes32 px, bytes32 message, bytes32 e, bytes32 s) public pure returns (bool)
```

Checks a Schnorr proof that the prover knows the private key of the point (px, parity).

*Dev:* Returns false (never reverts) on out-of-range inputs, on a failed ecrecover, or on a challenge mismatch. Computes h = n - s*px and sigma = n - e*px (mod n), so ecrecover(h, parity+27, px, sigma) = address(s*G - e*P). If s*px or e*px is 0 mod n, h or sigma becomes n, which ecrecover rejects (harmless).

| Parameter | Type | Description |
|---|---|---|
| `parity` | `uint8` | y-parity of the public key P (0 or 1). |
| `px` | `bytes32` | x-coordinate of the public key P; must be non-zero and below n. |
| `message` | `bytes32` | Context bound into the challenge (carry any nonce here). |
| `e` | `bytes32` | Fiat-Shamir challenge, below n. |
| `s` | `bytes32` | Response s = k + e*x mod n, below n. |

**Returns:** True if the recomputed challenge equals `e`.
