## contract `IdentityCommitments`

**IdentityCommitments** · CVIN research project

Identity-bound commitments in contract state, settable only by the identity's current owner.

*Dev:* Exists because ERC-1056 keeps attributes in events only, which no contract can read (Phase 1 register #49). A commitment counts only while unexpired and while its setter still owns the identity (AR-6). It proves registration of a public digest, not knowledge of the value behind it (AR-5).

- **standard:** ERC-1056 Ethereum Lightweight Identity (https://github.com/ethereum/EIPs/issues/1056)
- **security:** A commitment (salted hash or ciphertext digest) is public; validity is not knowledge (AR-5).
- **see:** docs/smart-contracts/05-zkp-and-idtx.md (section 3.4)
- **see:** phase2/idtx/test/idtx.test.js

## contract `IdtxExecutor`

**IdtxExecutor** · CVIN research project

Identity-dependent transactions (IDTx): an action runs only if a predicate over a named ERC-1056 identity holds, either in the same transaction (`execute`) or at a later fulfilment (`createIntent`/`fulfil`).

*Dev:* Three plaintext dependency kinds: Owner, Delegate (time-bounded), Commitment (registered-commitment validity). The caller is never part of the predicate (AR-4). The predicate is re-evaluated at fulfilment, so there is no on-chain time-of-check/time-of-use gap. Actions are events only (no external call, no value transfer). Prototype: no number from it is a result (Phase 2 principle 4).

- **standard:** ERC-1056 Ethereum Lightweight Identity (https://github.com/ethereum/EIPs/issues/1056)
- **security:** Anyone can create intents; `_intents` can be spammed (storage growth paid by the spammer). `creator` is stored but never read.
- **security:** The Commitment kind proves no knowledge of the committed value (AR-5); see ZkVinGate for knowledge-of-opening.
- **security:** An out-of-range `fulfil(id)` reverts with panic 0x32.
- **see:** docs/smart-contracts/05-zkp-and-idtx.md (section 3.4)
- **see:** phase2/idtx/test/idtx.test.js
- **see:** phase2/idtx/mutate_idtx.sh (mutation probe)
