## contract `ReentrantVinReceiver`

**ReentrantVinReceiver (test-only attacker)** · CVIN research project

Test fixture: an ERC-721 receiver that re-enters `CVINVehicleNFT.mintVehicle` from `onERC721Received` with the same VIN, to prove the one-token-per-VIN invariant holds during the `_safeMint` callback.
