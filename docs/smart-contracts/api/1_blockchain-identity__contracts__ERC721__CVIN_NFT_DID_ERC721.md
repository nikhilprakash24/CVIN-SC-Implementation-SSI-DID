## contract `CVIN_NFT_DID_ERC721` is `ERC721`, `ERC721URIStorage`, `Ownable`, `ERC2981`

**CVIN_NFT_DID_ERC721** · CVIN research project

OpenZeppelin-based ERC-721 vehicle NFT with ERC-2981 royalties and a toll scenario (the toll operator records zone entries; the token holder pays the toll).

*Dev:* Inherits OpenZeppelin Contracts 5.0.2 ERC721, ERC721URIStorage, Ownable and ERC2981. The owner mints with a caller-chosen tokenId via `_mint` (not `_safeMint`). The constructor sets a default royalty. `_baseURI()` is hard-coded, so stored URIs are PREFIXED by it (e.g. "ipfs://x" resolves to "https://baseuri.example.com/ipfs://x"). Despite the name, there is no VIN binding and no DID string. Used for the OZ-vs-monolithic gas comparison with CVIN_NFT_DID_ERC721_Monolithic.

- **standard:** ERC-721 Non-Fungible Token (core + Metadata) https://eips.ethereum.org/EIPS/eip-721
- **standard:** ERC-2981 NFT Royalty Standard https://eips.ethereum.org/EIPS/eip-2981
- **standard:** ERC-165 Standard Interface Detection https://eips.ethereum.org/EIPS/eip-165
- **security:** payToll does not check that an entry was recorded and accepts any positive amount.
- **security:** Royalties on a vehicle identity are a carry-over from the NFT template.
- **security:** The stored URI is prefixed by the placeholder base URI.
- **see:** docs/smart-contracts/03-token-standards-erc721-erc1155-lsp8.md
