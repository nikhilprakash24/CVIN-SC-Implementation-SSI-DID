## contract `CVINVehicleAccount` is `IAccount`

**CVINVehicleAccount** · CVIN research project

ERC-4337 smart-contract account representing a connected-vehicle identity; the address is the identifier, the owner key can be rotated or recovered.

*Dev:* See the file header above for the full list of simplifications vs the canonical v0.7 stack (npm account-abstraction/contracts) and the CVIN identity features. Self-contained (no OpenZeppelin imports, though the project pins OZ 5.0.2). Signature check follows the SimpleAccount v0.7 pattern (EIP-191 over userOpHash). Omitted: validAfter/validUntil packing, factory/CREATE2 counterfactual deployment, paymaster, aggregation, ERC-1271.

- **standard:** ERC-4337 (Account Abstraction, v0.7 shapes) https://eips.ethereum.org/EIPS/eip-4337
- **standard:** EIP-191 (signed data) https://eips.ethereum.org/EIPS/eip-191
- **security:** A single guardian can take over the account immediately via {recoverOwner}: no timelock, threshold or owner veto.
- **security:** No EIP-2 low-s check and no v normalisation in {_validateSignature}; harmless here because replay protection is the EntryPoint nonce.
- **see:** docs/smart-contracts/04-account-claim-identity-erc725-735-4337-combined.md (section 4a)
- **see:** sandbox/options/erc-4337/adapter.js
