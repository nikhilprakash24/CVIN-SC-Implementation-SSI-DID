# Roots Phase 2 — Figures Index (FIG-R7 … FIG-R14)

v0-1 · 2026-10-23 · generated by `make_phase2_figures.py` (run `python3 docs/roots/phase2/figures/make_phase2_figures.py` from the repo root). Inputs are the v0-1 first-pass documents R6 and R8, so regenerate after their v0-2 pass.

The script reads R6 and R8 directly. Table views (FIG-R8, R10, R11, R12, R13) are parsed from the markdown. Diagram views (FIG-R7, R9, R14) use curated item lists, and every tag in them is checked against the source text (R6, R8, the shared brief, the Phase 1 docs). If any printed tag is missing from those sources, the script exits non-zero. All SVGs pass `xml.dom.minidom` parsing, are 1000 px wide, use no text smaller than 9 px, and load no external fonts or images.

**Shared conventions.** Layer colours follow Phase 1: L0 grey · L1 red · L2 purple · L3 blue · L4 green · L5 orange · L6 yellow · L7 teal. **LH** (hardware, new in Phase 2) uses dark slate/brown. Status markers: MEASURED solid green · DERIVED solid blue · I (implemented-unmeasured, or "used" in R6) teal outline · DESIGN dashed orange on grey · ESTIMATED amber hatch · empty / not used white with a grey outline.
