# A1 poster (Phase 6)

`cvin_v2v_poster_A1.pdf` is a single page, 594 × 841 mm. The text and layout
are vector; the figures are the committed PNGs at native resolution.
`cvin_v2v_poster_A1_preview.png` is a 60 dpi preview.

```bash
python3 docs/visual/poster/build_poster.py
```

The rows, top to bottom:

1. The road frame (hero).
2. The latency strip, with the attack board beside it.
3. The contact matrix and cold vs warm.
4. The rogue's rejections, what the pictures may claim, and the #27 headline number.
5. Where cold latency goes.

The footer points to `docs/visual/FIGURES.md` and the replay. There are no
generated illustrations on the poster; those are Phase 7.
